# New Architecture Root

This folder contains the new optimized architecture for the Next.js AI Chatbot.

## Structure

- `app/` - Next.js 16 App Router
- `lib/` - Core libraries (errors, auth, data, cache, ai)
- `components/` - React components
- `features/` - Feature modules
- `shared/` - Cross-cutting utilities
- `types/` - TypeScript type definitions
