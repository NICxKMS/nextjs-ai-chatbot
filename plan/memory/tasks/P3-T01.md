## Findings

1. **Static models are curated, not exhaustive.** The old app had 30+ curated models including image/video generation models and Cloudflare Gateway variants. The new catalog includes only the 10 most relevant chat models across the three registered providers (google: 4, openai: 2, openrouter: 4). The OpenRouter discovery mechanism fills the gap dynamically. This is intentional simplification — future tasks can extend `STATIC_MODELS` as needed.

2. **Cache tag alignment.** `cacheTag('models')` aligns with `cacheKeys.models()` defined in `lib/cache/keys.ts` and the existing `invalidateModels()` / `revalidateTag` utilities in `lib/cache/revalidate.ts`. No new cache infrastructure was needed.

3. **Cookie name `chat-model`.** Matches the behavioral reference from the old app and plan docs (`plan/behavioral_extraction/features.md`, `plan/ui_parity/interactions.md`). The cookie write (client-side) will be handled by the model selector component in P3-T19.
