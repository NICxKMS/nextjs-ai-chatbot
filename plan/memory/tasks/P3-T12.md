## Deviations
**1. `onChatChange` callback instead of direct `artifactStore.reset()` call**
- **Plan said:** `useChatSideEffects` calls `artifactStore.reset()` directly on navigation
- **What was done:** Added optional `onChatChange?: () => void` callback parameter; ChatShell (P3-T21) will wire `artifactStore.reset` when connecting
- **Why better:** The artifact store module (`features/artifacts/lib/artifact-store.ts`) doesn't exist yet (P4 territory). Direct import would create a compile error or require out-of-scope stub creation. This follows the same dependency inversion pattern used by StreamBridge (P3-T20: "does NOT import artifactStore — wired in P4-T17"). ChatShell passes `onChatChange={artifactStore.reset}` when the store is available.
- **Trade-off:** ChatShell must remember to wire the callback. Documented for P3-T21.

**2. `status` parameter aliased as `_status`**
- **Plan said:** Hook accepts `{id, status, messages}`
- **What was done:** `status` is accepted in the interface but aliased to `_status` in destructuring to satisfy Biome's `noUnusedFunctionParameters` rule
- **Why:** The status parameter is part of the public API contract (ChatShell passes it), but no current effect uses it. Future effects (e.g., optimistic sidebar updates on status transition) will consume it. Keeping it in the interface ensures the contract is stable.

## Findings
**1. Artifact store forward-reference pattern**
P3-T21 (ChatShell) will need to pass `artifactStore.reset` as the `onChatChange` callback when wiring `useChatSideEffects`. This is the same deferred-wiring pattern as StreamBridge (P3-T20 / P4-T17). Both P3-T21 and P4-T17 should be aware.

**2. Old app scroll hook used scroll events + SWR**
The old `useScrollToBottom` (oldapp/hooks/use-scroll-to-bottom.tsx) used scroll events, ResizeObserver, MutationObserver, and SWR for scroll flagging. The new implementation is dramatically simpler (~45 lines vs ~125 lines) using IntersectionObserver as the sole detection mechanism, eliminating all observer overhead and SWR dependency.
