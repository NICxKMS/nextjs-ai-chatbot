## Summary

Created `lib/data/user.ts` with four exported functions for user data access:

- `getUserByEmail(email)` — returns `User | null`, normalizes email to lowercase
- `getUserById(id)` — returns `User | null`
- `createUser(data)` — returns `User`, wraps DB errors in `AppError.internal("internal_error:database:query_failed", ...)`
- `updateUserLastLogin(id)` — returns `void`, sets `lastLogin` to `new Date()`

## Design Decisions

- `getUserByEmail` returns `null` when not found (not throw) — spec requirement for login flow
- `createUser` adds a row-existence guard after `.returning()` since Drizzle types the destructured result as potentially `undefined`
- All errors wrapped in `AppError.internal("internal_error:database:query_failed", ...)` with original error as details — explicit error codes per D014
- Email normalized to lowercase in `getUserByEmail` — matches oldapp behavior
