## Deviations

- **Spec said**: "Renders image via next/image or native img element"
- **Done instead**: Used native `<img>` exclusively with a biome-ignore directive
- **Why**: `next/image` does not support base64 data URLs (the primary use case for Pyodide/matplotlib output). Using native `<img>` with `decoding="async"` and manual loading states provides equivalent UX. The oldapp reference (`oldapp/components/elements/image.tsx`) also uses native `<img>` for the same reason.
- **Trade-offs**: No automatic next/image optimization for regular URL images, but the primary content source is base64 data URLs from code execution.
