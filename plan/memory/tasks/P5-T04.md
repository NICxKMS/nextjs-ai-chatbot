## Deviations
- **Rename: added PencilEditIcon + inline edit** — The old app had no rename action in the sidebar dropdown. The new spec requires it (P5-T09 dependency). Implemented as inline `<input>` that replaces the link text, focused via `useEffect` instead of `autoFocus` (Biome a11y rule `noAutofocus` forbids the attribute). Enter submits, Escape cancels, blur submits. Calls `renameChat` server action directly.
- **Share submenu conditionally rendered** — Old app always rendered the share submenu using `useChatVisibility` hook. New implementation renders the share submenu only when `onVisibilityChange` prop is provided (stub pattern per spec). This avoids importing visibility-related hooks that don't exist until P6.
