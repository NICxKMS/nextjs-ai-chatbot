## Deviations
**Old app had no Retry button or error code display.** The old `ArtifactErrorBoundary` only showed a static error message and the raw `error.message`. The new version adds:
1. A **Retry button** (resets `hasError` state) — required by the task spec

5. Uses the shared `Button` component for the Retry action instead of raw HTML
