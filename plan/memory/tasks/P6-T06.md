## Summary

Created the visibility feature module with three files: types/Zod schema, a Server Action for updating chat visibility, and a `useChatVisibility` hook for consumers outside `ChatSessionContext` (e.g., `SidebarHistoryItem`).

## Files Changed

- `features/visibility/types/visibility.types.ts` — Created. Exports `VisibilityType` ("public" | "private"), `updateVisibilitySchema` (Zod: chatId UUID + visibility enum), and inferred `UpdateVisibilityRequest` type.
- `features/visibility/actions/update-visibility.ts` — Created. `"use server"` action `updateChatVisibility(input)`. Flow: auth check → Zod validation → ownership verification → DB update via `lib/data/chat.ts` → `invalidateChat()` + `invalidateChatList()` cache invalidation. Returns `ActionResult<void>`.
- `features/visibility/hooks/use-chat-visibility.ts` — Created. `"use client"` hook `useChatVisibility(chatId, initialVisibility)`. Uses React 19 `useOptimistic` + `useTransition` for instant optimistic updates. Calls Server Action for persistence. On failure: `useOptimistic` auto-reverts when transition completes + shows `toast.error`. Returns `{ visibilityType, setVisibilityType, isPending }`.
