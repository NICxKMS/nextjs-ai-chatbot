## Summary

Created the `useVotes` hook and `VoteButtons` component for the voting feature. The hook uses React 19 `useOptimistic` with `useTransition` for instant optimistic vote updates via the `voteOnMessage` Server Action, with automatic rollback and toast error on failure. The component renders ThumbUp/ThumbDown buttons for assistant messages only, with `aria-pressed` state, `data-testid` attributes, disabled no-op for active votes with full-opacity highlight, and hidden buttons for guest users.

## Deviations

1. **Added `vote` and `onVote` props to VoteButtons**: The task spec lists only `chatId, messageId, isAssistant, isLoading` as props, but VoteButtons needs vote data and a submit callback to function. P6-T03 will create VotesProvider context with `useVoteForMessage(messageId)` — at that point VoteButtons can be modified to read from context instead. For P6-T02, explicit props make the component testable and functional standalone without the context that doesn't exist yet.
2. **Added `isPending` to useVotes return**: The spec only mentions `votes` and `submitVote` as return values. Added `isPending` (from `useTransition`) for consumers that may want to show loading state during vote submission. Follows the `useChatVisibility` pattern which also exposes `isPending`.
3. **Used `disabled:opacity-100` override for "filled/highlighted" state**: The spec requires "filled icon when active vote exists." Since the `disabled` attribute adds `disabled:opacity-50` from the button base styles, the active vote button additionally gets `text-foreground disabled:opacity-100` to maintain full visual prominence while being functionally disabled (no-op via `disabled` + `disabled:pointer-events-none`).

## Findings

1. **P6-T03 integration surface**: VoteButtons currently accepts `vote` and `onVote` as explicit props. P6-T03 should modify VoteButtons to import `useVoteForMessage(messageId)` from `vote-resolver.tsx` and call `useVotes.submitVote` from VotesProvider context, removing the need for these props. The component is designed to make this transition straightforward.
2. **Existing message-actions.tsx has placeholder vote buttons**: `features/chat/components/message-actions.tsx` already renders ThumbUp/ThumbDown buttons with `TODO(P6)` comments. P6-T03 should either replace those inline buttons with `<VoteButtons>` or remove them in favor of rendering `<VoteButtons>` from `message.tsx`. The current inline buttons use `toast.info("Voting will be available soon")` as placeholders.
