- **P3-T16/P3-T17 consumers**: `ChatMessage` does NOT include `MessageActions` (copy, vote, edit). Per task spec, those are P3-T16. The Messages list (P3-T17) should compose `ChatMessage` + `MessageActions` per message.
- **ArtifactToolResult is a stub**: Returns a minimal confirmation card. Full artifact tool result rendering (with preview) depends on `features/artifacts/components/` from P4. The component accepts `toolCallId` and `output` so it can be replaced by a proper implementation.
