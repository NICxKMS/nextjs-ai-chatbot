## Deviations

### Dark variant selector

- **Plan said:** `@custom-variant dark (&:is(.dark *))` (task description)
- **Oldapp had:** `@custom-variant dark (&:is(.dark, .dark *))` (includes `.dark` element itself)
- **What was done:** Used `(&:is(.dark *))` per task spec
- **Why:** The `.dark` class is applied to `<html>`, which rarely needs dark styles directly — only descendants do. The simpler selector is more precise. Standard shadcn/ui v4 pattern.

### Excluded oldapp-specific imports

- **Oldapp had:** `@import "react-data-grid/lib/styles.css"`, `@source '../node_modules/streamdown/dist/index.js'`, `@plugin "tailwindcss-animate"`
- **What was done:** Excluded all three
- **Why:** These are component-specific (react-data-grid, streamdown) or not in project dependencies (tailwindcss-animate). They should be added by consuming tasks when needed, not in core globals.

### Excluded component-specific styles

- **Oldapp had:** `.skeleton`, `.ProseMirror`, `.cm-editor`, `.suggestion-highlight` class styles
- **What was done:** Excluded
- **Why:** These are editor/component-specific styles that belong with their respective components (P0-T11, P3+), not in core CSS globals.

### Added print styles

- **Oldapp had:** No explicit print styles
- **What was done:** Added minimal `@media print` block
- **Why:** Task spec requested copying print styles. Added a basic block for future extension.
