## Deviations

**`generate-uuid.ts` — Simplified vs oldapp fallback chain**

- **Plan/oldapp**: oldapp `generateUUID()` has a 3-tier fallback: `crypto.randomUUID()` → `crypto.getRandomValues()` manual UUID assembly → throw Error.
- **What was done**: Single-line `crypto.randomUUID()` with no fallback.
- **Why**: This project targets Next.js 16 (Node 20+) and modern browsers only. `crypto.randomUUID()` is universally available in all supported runtimes. The fallback code is dead weight that adds complexity for zero benefit.
- **Trade-offs**: If someone runs this on Node <19, `generateUUID()` will throw at runtime. This is acceptable since the project requires Node 20+ anyway.
