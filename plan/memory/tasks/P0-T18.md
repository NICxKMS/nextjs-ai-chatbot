## Pre-Gate Fixes

### Fix 1: Toaster placement (app/layout.tsx)

**Problem:** `<Toaster />` was rendered outside `<ThemeProvider>`, preventing Sonner from auto-detecting dark mode via `next-themes`.

**Fix:** Moved `<Toaster />` inside `<ThemeProvider>`, after `{children}`. This matches the original `oldapp/` behavior.

### Fix 2: Invalid CSS function (app/globals.css)

**Problem:** `::-webkit-scrollbar-thumb:hover` used `--alpha(var(--muted-foreground) / 0.5)` which is not a valid CSS function. Browsers silently ignore it.

**Fix:** Replaced with `color-mix(in srgb, var(--muted-foreground) 50%, transparent)` — valid CSS with wide browser support.
