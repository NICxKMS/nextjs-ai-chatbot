## Deviations

**Extra file created: `features/artifacts/lib/suggestions-extension.tsx`**

- **Plan prescribed:** Single output file `features/artifacts/components/editors/text-editor.tsx`
- **What was done:** Created a companion `features/artifacts/lib/suggestions-extension.tsx` (206 lines)
- **Why:** The SuggestionsExtension (ProseMirror plugin + widget rendering + decoration helpers) is ~200 lines of self-contained library code. Inlining it would push the text editor well over the 200-line limit. The SEAM-032 description explicitly says "Build SuggestionsExtension for inline suggestion decorations" as part of this task's scope. Extracting it to `features/artifacts/lib/` follows the feature collocation pattern — it's a lib utility consumed by the text editor within the same feature.
- **Trade-offs:** One additional file not listed in the task spec's output files. However, this is the correct architectural placement (lib utility vs component) and keeps both files at manageable sizes.

**Simplified suggestion widget (no framer-motion animation)**

- **Plan/old app:** Old app `Suggestion` component used framer-motion AnimatePresence for expand/collapse toggle
- **What was done:** Simplified popup widget that shows immediately without animation, with accept/dismiss buttons
- **Why:** Reduces complexity and dependency on framer-motion in the ProseMirror widget layer (which uses `createRoot` for imperative rendering). The popup achieves the same UX goal — showing description + apply button. Animation can be added later if needed.
- **Trade-offs:** Slightly different visual feel (no expand/collapse animation), but functionally equivalent.
