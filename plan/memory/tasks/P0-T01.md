## Deviations

### 1. `next.config.ts` — Config options promoted to top-level

**Plan said:** Place `reactCompiler`, `cacheComponents`, and `ppr` inside `experimental: {}`.

**Done instead:** `reactCompiler` and `cacheComponents` at top-level NextConfig. Removed `ppr: 'incremental'`.

**Why:** Next.js 16.1.6 moved these options out of `experimental` to top-level. `ppr` is deprecated — its functionality is merged into `cacheComponents`. TypeScript compilation fails if placed inside `experimental` (`TS2353: 'reactCompiler' does not exist in type 'ExperimentalConfig'`).

**Trade-offs:** None — this is the correct API per the installed Next.js types.
