## Functions Implemented

| Function | Signature | Description |
|----------|-----------|-------------|
| `getArtifactById` | `(artifactId: string) → Promise<Artifact \| null>` | Latest version via ORDER BY createdAt DESC LIMIT 1 |
| `getArtifactVersions` | `(artifactId: string) → Promise<Artifact[]>` | All versions ordered by createdAt DESC |
| `saveArtifactVersion` | `(data: { id, title, content, kind, userId, chatId }) → Promise<Artifact>` | Insert new version row (composite PK allows same id) |
| `deleteArtifactVersionsAfter` | `(artifactId: string, createdAt: Date) → Promise<void>` | Delete version(s) at/after timestamp |

## Design Decisions

- **File is `artifact.ts`** — NOT `document.ts`, per naming rules
- **`ArtifactKind` type** — NOT `DocumentKind`, imported from `@/lib/types/models.types`
- **Composite PK versioning**: `(id, createdAt)` — each `saveArtifactVersion` creates a new row with same id
- **Bare-ID signatures**: No userId for reads — auth at caller level
- **Pure DB operations**: No `'use cache'`, no auth imports, no revalidation
- **Safe insert handling**: Checks `result[0]` for undefined and throws explicit error
