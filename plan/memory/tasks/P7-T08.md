## Findings

- The AI SDK in this project is `@ai-sdk/provider@2.0.0` which exports `LanguageModelV2` (not V1). Key V2 differences: `specificationVersion: "v2"`, `supportedUrls` instead of `supportsUrl`, `doGenerate` returns `content: LanguageModelV2Content[]` (array of union types) instead of flat `text`/`toolCalls`, `doStream` returns `{ stream }` without `rawCall`/`warnings`, streaming uses `text-start`/`text-delta`/`text-end` lifecycle parts instead of flat `text-delta`, tool calls use `input` field instead of `args`, and usage requires `totalTokens` alongside `inputTokens`/`outputTokens`. Future test tasks (P7-T07) should use these V2 mocks directly.
