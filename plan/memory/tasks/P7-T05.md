## Deviations

**Spec said:** `instrumentation-client.ts` should "Export onRequestError hook for error reporting."

**What was done:** `onRequestError` was placed in `instrumentation.ts` (server-side) instead. `instrumentation-client.ts` uses `window.addEventListener("error", ...)` and `window.addEventListener("unhandledrejection", ...)` for client-side error capture.

**Why:** Per Next.js 16 docs (`.next-docs/01-app/03-api-reference/03-file-conventions/instrumentation.mdx`), `onRequestError` is a **server-side** export that belongs in `instrumentation.ts`. The client-side file (`instrumentation-client.ts`) does not support this export — it runs arbitrary code before hydration and optionally exports `onRouterTransitionStart`. The deviation moves the hook to its correct location per the framework's API contract.

**Trade-offs:** None — this is strictly more correct.
