## Summary

Created two pure function modules for the chat feature: callback factories (`chat-callbacks.ts`) that extract side-effects from the chat orchestrator for testability, and `processStreamDelta` (`process-stream-deltas.ts`) that handles all artifact-* data part types as a pure state transformation function.

## Files Changed

- `features/chat/lib/chat-callbacks.ts` — Created. Exports three callback factories: `createOnMessageCallback`, `createOnTitleCallback`, `createOnErrorCallback`. Each accepts injected dependencies (e.g., `saveMessage`, `updateTitle`) and returns a typed callback function. Uses structural typing for dependency parameters so any compatible function can be injected (test stubs, real data layer, etc.).
- `features/chat/lib/process-stream-deltas.ts` — Created. Exports `processStreamDelta(delta: DataPart, current: UIArtifact): { artifact: UIArtifact }` pure function. Handles all 12 DataPart union members with correct semantics: artifact-id (SET + streaming + visible), artifact-title/kind (SET), artifact-clear (RESET content + suggestions), artifact-finish (idle), artifact-textDelta (APPEND), artifact-codeDelta/sheetDelta/imageDelta (REPLACE), artifact-suggestion (APPEND to array), chat-title/error (pass-through). Includes exhaustiveness guard via `never` type in default case. Also exports `DEFAULT_ARTIFACT` constant for reference.
