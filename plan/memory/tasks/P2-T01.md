## Deviations

### AppSession type location

**Plan says:** AppSession type lives in `features/auth/types/auth.types.ts` (shared-types.md §12), created by P2-T02.

**What was done:** AppSession type is defined and exported from `lib/auth/session.ts` directly.

**Why:** P2-T02 has not been created yet, and `getAppSession` needs to return this type. Co-locating the type with the function that produces it (matching the old app's pattern in `oldapp/lib/auth/session.ts`) is the simplest approach. P2-T02 can re-export `AppSession` from `@/lib/auth/session` to maintain the planned import paths. This avoids a circular dependency (session.ts importing from features/auth/) and keeps infrastructure types in the infrastructure layer.

**Trade-off:** Consumers that expect `AppSession` from `features/auth/types/auth.types.ts` will need a re-export, not a definition — P2-T02 should handle this.

### Guest session stub

**Plan says:** Guest path verifies JWT via `verifyGuestToken` from `features/auth/lib/guest.ts`.

**What was done:** Guest path reads the cookie but returns null. A clear TODO(P2-T03) documents the wiring point.

**Why:** P2-T03 creates `verifyGuestToken`. Rather than creating a broken import or a local stub function, the cleanest approach that typechecks is to read the cookie (proving the pipeline works) and defer verification to P2-T03. This was explicitly allowed by the task assignment.

### server-only dependency

**Plan says:** Not explicitly mentioned.

**What was done:** Added `server-only` to `package.json` dependencies.

**Why:** `lib/cache/client.ts` already imports `server-only` but the package was not declared in `package.json`. The `lib/auth/session.ts` also needs it. This is a correctness fix, not scope creep.

## Findings

### F1: AppSession re-export needed in P2-T02

P2-T02 (`features/auth/types/auth.types.ts`) should re-export `AppSession` from `@/lib/auth/session` rather than redefining it, to maintain a single source of truth. Recommended:
```typescript
export type { AppSession } from "@/lib/auth/session"
```

### F2: Guest session wiring point for P2-T03

`resolveGuestSession()` in `lib/auth/session.ts` has a clear TODO(P2-T03) marker. P2-T03 needs to:
1. Create `verifyGuestToken` in `features/auth/lib/guest.ts`
2. Update `resolveGuestSession()` to import and call it
