## Deviations

1. **Property naming: `chatStream` instead of `ChatStream`**
   - Plan/redesign spec uses `ChatStream` (PascalCase) as the state property name in the context value
   - Implementation uses `chatStream` (camelCase) instead
   - Why: AGENTS.md naming conventions mandate camelCase for all non-component, non-type, non-constant identifiers. A state property inside an interface is a regular field, not a component or type. This aligns with the project's consistent use of camelCase for all hook return fields (e.g., `useSettings()` returns `temperature`, not `Temperature`).
   - Trade-off: Consumers (P3-T11 useChatSession, P3-T20 StreamBridge) must use `chatStream` not `ChatStream`. This is trivial and improves consistency.

2. **Cleanup effect added for RAF on unmount**
   - The redesign reference code sketch does not include `cancelAnimationFrame` cleanup on unmount
   - Implementation adds a `useEffect` cleanup that cancels any pending RAF on component unmount
   - Why: Prevents potential memory leaks and stale state updates if the provider unmounts while RAF is pending (e.g., during page navigation). Standard React cleanup pattern.
   - Trade-off: None — strictly an improvement.
